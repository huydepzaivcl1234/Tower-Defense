Tower Defense — Unity 3D Roguelite Strategy Game

Role: Game Developer / Game Designer
Tech: Unity 6.5, C#, URP, DOTween, TextMeshPro, DialogueEditor

Developed a 3D Tower Defense game combining strategic tower placement with roguelite progression systems. Built data-driven Tower, Enemy, Wave, Relic and Quest systems with customizable stats and runtime modifiers. Implemented NPC dialogue with cinematic camera focus, quest selection by difficulty, live quest tracking, relic drops, tower upgrades, game-speed controls, responsive UI, pause/settings, win/lose flow, portal VFX and object pooling optimizations.

Key contributions:

Designed and implemented modular Tower / Enemy / Wave combat systems.
Built stackable Relic system with rarity, drops, selection UI and gameplay modifiers.
Developed NPC Dialogue + Quest system with Easy/Medium/Hard quests and dynamic quest availability.
Created responsive gameplay HUD, upgrade UI, Relic HUD and Quest Live HUD.
Implemented enemy/projectile/VFX pooling and MaterialPropertyBlock optimizations.
Designed systems to be highly configurable through Unity Inspector and ScriptableObjects.
